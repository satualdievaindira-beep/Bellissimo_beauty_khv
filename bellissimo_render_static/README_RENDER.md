# Bellissimo Beauty Salon — Render Static Site

Это полностью статическая версия сайта: Python/Flask для Render больше не нужен.

## Render
Создайте **Static Site** и укажите:
- Build Command: оставить пустым
- Publish Directory: `.`
- Auto-Deploy: по желанию

Если загружаете ZIP вручную, распакуйте его в репозиторий и подключите репозиторий к Render.

## Что работает
- адаптивный дизайн;
- фильтры услуг;
- полный прайс из исходного проекта;
- форма выбора услуги, даты и времени;
- предварительный просмотр сообщения;
- переход в WhatsApp с готовым текстом;
- 2ГИС;
- мобильное меню;
- FAQ.

Сервер для записи не нужен: форма сразу открывает WhatsApp.
